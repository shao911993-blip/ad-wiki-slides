Denoising Diffusion Probabilistic Models (DDPM)

建立擴散機率模型與多尺度去噪分數匹配及退火朗之萬動力學之數學等價關聯，提出預測高斯雜訊 \(\boldsymbol{\epsilon}\) 的參數化與簡化訓練目標 \(L_{\text{simple}}\)，成為後續擴散式異常檢測重建方法的核心基礎。

Reconstruction by Inpainting for Visual Anomaly Detection (RIAD)

將異常檢測轉為自監督遮罩修補問題，隨機挖空多尺度網格並由含 Skip Connections 之 U-Net 依鄰域修補，結合多尺度梯度相似度（MSGMS）於 MVTec AD 達 91.7% Image 與 94.2% Pixel ROC AUC。

Towards Total Recall in Industrial Anomaly Detection (PatchCore)

擷取 ImageNet 預訓練網路之中階局部鄰域聚合 Patch 特徵建立正常記憶庫，搭配貪婪核心集下採樣（Greedy Coreset Subsampling）大幅降低推論成本，於 MVTec AD 達單模型 99.1%（整合模型 99.6%）Image AUROC 與 98.1% Pixel AUROC。

2023 / 2025 (arXiv:2303.08730v4) 異常檢測方法

DiffusionAD: Norm-guided One-step Denoising Diffusion for Anomaly Detection

將異常檢測建模為「由雜訊恢復正常（Noise-to-Norm）」之擴散重建與 U-Net 分割雙子網路，透過一步去噪（One-step Denoising）將推論速度提升至 23.5 FPS，並以規範引導雙尺度去噪（NOD）兼顧大尺度無異常語意與小尺度正常細節，於 MVTec AD（99.7% I-AUROC / 76.1% AP）及 VisA 全面刷新 SOTA。

Applied Soft Computing 2026 異常檢測方法

Memory bank-guided diffusion model for lightweight anomaly detection (LAMBDA)

將一步去噪擴散模型移至預訓練 VAE 潛在空間（64 倍空間降維），提出記憶庫引導去噪（MBG）與引導尺度圖（GSM）取代像素空間雙尺度加噪分支，使訓練峰值 GPU 記憶體大幅降低 80.8%（48.4 GB → 9.3 GB）、推論達 42.3 FPS（23.6 ms，出自 Table 1），並於醫療基準 BMAD 拿下 87.1% Image AUROC 與 75.5% mAD 最高表現（出自 Table 2）。
